# 🎡 SGIS 럭키 룰렛 (SGIS Lucky Roulette)

인터넷 연결이 전혀 없는 환경(오프라인)에서도 완벽하게 동작하는 행사 및 전시 부스용 경품 추첨 룰렛 프로그램입니다.  
개발 단계에서는 기능별(CSS, JS, 뷰)로 모듈화하여 개발되었으며, 빌드 스크립트를 통해 **단 하나의 HTML 파일**로 통합 산출되어 더블클릭만으로 즉시 실행됩니다.

---

## 🌟 주요 특징

1. **완벽한 오프라인 작동 (Zero External Dependencies)**
   - 외부 CDN(Google Fonts, cdnjs, FontAwesome 등) 및 외부 이미지/사운드 파일 의존성 **0%**
   - Web Audio API를 활용한 자체 신디사이징 사운드 (스핀 틱틱 소리, 팡파레 축하음)
   - 순수 HTML5 Canvas 2D 기반 축하 폭죽(Confetti) 파티클 시스템 내장

2. **SGIS 및 국가데이터처 기관 정식 브랜딩 적용**
   - 상단 헤더, 메인 배너 및 브라우저 탭에 **SGIS 럭키 룰렛** 브랜드 적용 (SGIS 블루 포인트)
   - 부스 모드 우측 라인업 최상단에 **SGIS plus & 통계지리정보서비스** 및 **대한민국 정부 상징 태극 + 국가데이터처** 정식 벡터 SVG 로고 헤더 탑재

3. **행사장/전시부스 맞춤 모드 (Booth Mode)**
   - **🎪 부스 모드**: 방문객에게 보일 때 관리자 패널을 숨기고 좌측 룰렛 뷰와 우측 경품 라인업을 웅장하게 집중 표시
   - **1:1 완벽 정렬**: 좌측 `wheel-section`과 우측 `booth-showcase-panel`의 높이와 시작점/끝점을 1px 오차 없이 1:1로 완벽 동기화
   - **초고속 회전(0.8초)**: 대기열 지연을 방지하는 1초 이내 쾌속 회전 애니메이션
   - **⤢ 전체 화면**: 브라우저 툴바 없이 모니터/빔프로젝터/태블릿에 꽉 찬 화면 연출

4. **경품 및 수량(재고) 스마트 관리**
   - **2:3 황금비율 자동 정렬 프리셋 (`⚖️ 2:3 비율 정렬`)**: 대용량 품목과 소용량 품목을 2:3 비율로 자동 교차 배치
   - **순서 조정 UI**: 각 경품별 위/아래 이동(`▲`/`▼`) 및 순위 배지(#1~#12)
   - **수량 비례 / 균등 면적 선택**: 수량 비례 슬라이스 또는 1/N 균등 슬라이스 지원
   - 품절(0개) 경품 자동 숨김 및 대기 품목 자동 승격

5. **현장 최적화 단축키 지원**
   - **Space / Enter**: 룰렛 돌리기 및 당첨 팝업 [수령완료] 즉시 닫기
   - **C (또는 ㅊ)**: 테스트 스핀 또는 오작동 시 수량 1개 즉시 원복(복원) 후 팝업 닫기
   - **P**: 운영자 관리창 열기 / 부스 모드 전환 토글

6. **데이터 영속성 및 관리**
   - 브라우저 로컬 저장소(LocalStorage)에 실시간 자동 저장 (새로고침해도 상태 보존)
   - 당첨 히스토리 기록 및 **Excel 호환 CSV 내보내기** (한글 깨짐 없는 UTF-8 BOM 적용)
   - 전체 설정 및 경품 데이터 **JSON 백업 및 복원** 지원
   - 수량만 초기 개수로 원복하는 '수량 리셋' 버튼 제공

## 📁 프로젝트 구조

```
경품추첨기/
├── src/                          # 개발용 모듈화 소스코드
│   ├── index.html                # 메인 HTML 마크업
│   ├── css/
│   │   ├── base.css              # 전역 스타일, 레이아웃 및 테마 변수
│   │   ├── wheel.css             # 룰렛 캔버스 래퍼, SPIN 버튼, 애니메이션
│   │   ├── admin.css             # 경품 관리 패널, 탭, 통계, 순서/수량 조절 버튼
│   │   └── modal.css             # 당첨 결과 팝업, 축하 모달, 부스 모드 1:1 정렬 스타일
│   └── js/
│       ├── audio.js              # Web Audio API 기반 오프라인 사운드 엔진
│       ├── confetti.js           # Canvas 2D 기반 축하 꽃가루 폭죽 파티클
│       ├── storage.js            # LocalStorage 및 데이터 백업/CSV 내보내기
│       ├── wheel.js              # 고해상도 Canvas 2D 룰렛 물리 및 렌더링 엔진
│       ├── qr-scanner.js         # QR 코드 리더 엔진
│       ├── lib/jsQR.js           # 오프라인 QR 디코딩 라이브러리
│       └── app.js                # 전체 UI 컨트롤러, 이벤트 바인딩 및 키보드 단축키
│
├── build.js                      # 단일 HTML 번들러 스크립트 (순수 Node.js 내장 모듈 사용)
│
├── dist/
│   └── index.html                # 📦 최종 산출물: 단일 HTML 파일
│
└── 경품추첨_돌림판_단일파일.html      # 🚀 루트 경로에서 바로 실행 가능한 단일 HTML 복사본
```

## 🚀 실행 및 빌드 방법

### 1. 즉시 실행 (사용자 배포)
- `dist/index.html` 또는 `경품추첨_돌림판_단일파일.html`을 **더블클릭**하면 인터넷 연결 없이 크롬, 엣지, 웨일 등 모든 웹 브라우저에서 바로 실행됩니다.
- USB에 복사하여 인터넷이 안 되는 전시 행사장 노트북이나 태블릿에 옮겨서 바로 사용하실 수 있습니다.

### 2. 코드 수정 후 빌드
소스 코드를 수정한 후 단일 파일로 다시 합치려면 터미널에서 아래 명령어를 실행하세요.
(외부 npm 패키지 설치 필요 없이 순수 Node.js만으로 즉시 빌드됩니다.)

```bash
node build.js
```

## ⚙️ 단축키 안내

| 키 | 동작 | 설명 |
| :---: | :--- | :--- |
| **Space** / **Enter** | 룰렛 회전 / 확인 | 중앙 SPIN 버튼 누름 및 당첨 모달 즉시 닫기 |
| **C** (또는 **ㅊ**) | 당첨 차감 취소 | 테스트 회전 시 차감된 경품 1개 즉시 복원 |
| **P** | 관리창 토글 | 부스 모드 ↔ 운영자 관리창 전환 |
| **Esc** | 모달 닫기 | 열려 있는 팝업 및 관리창 닫기 |
